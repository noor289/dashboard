# Brew Analytics: Café Analytics Dashboard

A responsive café analytics dashboard built with **Bootstrap 5**, **jQuery**, and **Chart.js**.

## Live Demo

[View Live Dashboard](PASTE_YOUR_DEPLOYED_LINK_HERE)

## Features

- Collapsible sidebar navigation with toggle open/close on desktop and mobile, including an overlay and backdrop on mobile
- Three dashboard tabs:
  - **Overview**: key stat cards, weekly sales trend, best-selling drinks, and revenue by category
  - **Menu Performance**: best-selling drinks breakdown and full menu items table
  - **Sales Trends**: monthly revenue trend and this-week-vs-last-week comparison
- Summary stat cards for today's revenue, cups sold, best seller, and average order value
- Interactive line, doughnut, and bar charts using Chart.js
- "Refresh Data" button that simulates live data updates on the Overview stat cards
- Custom café-themed color palette and typography using Montserrat and DM Sans
- Fully responsive layout

## Tech Stack

- HTML5 / CSS3
- Bootstrap 5 (CDN)
- jQuery (CDN)
- Chart.js (CDN)
- Google Fonts (Montserrat, DM Sans)
